# ConorDyson.github.io

Personal website of Conor Dyson, served by GitHub Pages. Plain HTML and CSS, no build step.

- `index.html`: home (hero with the spiral-wake record, research themes, bio, selected papers)
- `research.html`: themes, full publication list, code
- `about.html`: background, timeline, rugby, music and art
- `assets/site.css`: all styling (maroon and cream, Big Shoulders Display + Instrument Sans)
- `assets/spiral-wake.svg`: hero image, generated by `tools/spiral_wake.py`
- `assets/ConorDyson_CV.pdf`: CV (replace this file to update it)

## Common edits

- **Add a paper:** in `research.html`, copy one `<li>…</li>` block inside `<ol class="papers">`, paste it at the top
  and change the year, title, authors and links. To feature it on the home page, do the same in `index.html`.
- **Update the CV:** upload a new PDF named `ConorDyson_CV.pdf` into `assets/`, replacing the old one.
- **Change the hero image:** `python tools/spiral_wake.py 0.25 24 3.8 0.25`, then copy `/tmp/spiral/spiral.svg`
  to `assets/spiral-wake.svg` (arguments: disc aspect ratio h, number of grooves, groove amplitude, crest threshold).

GitHub Pages: Settings → Pages → Build and deployment → Source "Deploy from a branch", branch `main`, folder `/ (root)`.
